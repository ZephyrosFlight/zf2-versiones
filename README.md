# ZephyrosFlight 2 — versiones para la Raspberry Pi

Programa ya compilado (sin código fuente). Última versión: **ZF2 1.15** (1641b24).

Instalar en una Raspberry Pi 5 con Raspberry Pi OS de 64 bits:

    curl -fsSL https://raw.githubusercontent.com/ZephyrosFlight/zf2-versiones/main/instalar.sh | bash

Después, el equipo se actualiza solo (AJUSTES › SISTEMA).
